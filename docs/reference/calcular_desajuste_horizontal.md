# Calcular desajuste horizontal entre campo de formacion y ocupacion

Compara el campo ARM8 con SINCO a tres digitos mediante la matriz
mexicana aceptada. Separa la base ocupada, el universo al que aplica y
el universo clasificable. SINCO `999` permanece pendiente y nunca cuenta
como desajuste.

## Usage

``` r
calcular_desajuste_horizontal(data, inicio = 20143L, matriz = NULL)
```

## Arguments

- data:

  Data frame con `anio`, `trim`, `sinco3d`, `clase2` y un campo ARM8
  (`campo_arm8_horizontal` o `campo_arm8`). Debe contener ademas
  `elegible_carrera` o `cs_p13_1`.

- inicio:

  Primer trimestre admisible, como entero `AAAAT`.

- matriz:

  Ruta alternativa a la matriz, principalmente para pruebas.

## Value

El data frame con las variantes estricta y amplia, indicadores de
universo y una razon trazable de no clasificacion.
